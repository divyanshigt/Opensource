# Contributing to OpenSource Hub

Thank you for your interest in contributing!

## How to Contribute

### 1. Fork the repository

Click the Fork button on GitHub.

### 2. Clone your fork

git clone YOUR_FORK_URL

### 3. Create a branch

git checkout -b feature/your-feature-name

### 4. Make your changes

Work only on the issue assigned to you.

### 5. Commit

git add .

git commit -m "Add: your feature name"

### 6. Push

git push origin feature/your-feature-name

### 7. Create a Pull Request

Open GitHub and create a Pull Request from your branch.

## Important Rules

- Do not work on an issue already assigned to another contributor.
- Comment on the issue before starting.
- Keep Pull Requests focused on one issue.
- Do not make unnecessary changes.
- Write meaningful commit messages.
- Be respectful to other contributors.
