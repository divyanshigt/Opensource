# 🚀 OpenSource Hub

Welcome to OpenSource Hub!

This repository is created to help beginners learn Open Source,
Git, GitHub, Issues and Pull Requests.

## 🛠️ Technologies

- HTML
- CSS
- JavaScript

## 🤝 How to Contribute

1. Fork this repository.
2. Clone your fork.
3. Create a new branch.
4. Choose an issue.
5. Make your changes.
6. Commit your changes.
7. Push your branch.
8. Create a Pull Request.

Please read `CONTRIBUTING.md` before contributing.
